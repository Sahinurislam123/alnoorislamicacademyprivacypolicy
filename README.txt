AL NOOR ISLAMIC ACADEMY — Privacy Policy

Files:
- index.html: Privacy Policy webpage for GitHub Pages.

How to publish:
1. Create a PUBLIC GitHub repository named: al-noor-privacy-policy
2. Upload index.html to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, select "Deploy from a branch".
5. Choose branch "main" and folder "/ (root)", then Save.
6. After deployment, the URL format will be:
   https://YOUR-GITHUB-USERNAME.github.io/al-noor-privacy-policy/

Important:
- Replace the placeholder email and address in index.html before publishing.
- Make sure the policy accurately matches the app's actual data collection and services.
